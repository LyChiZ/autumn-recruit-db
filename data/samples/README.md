# data/samples — 示例数据说明

本目录存放 **虚构脱敏示例**，用于演示、测试与文档截图，仓库内绝不存放真实数据。

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `sample_resume.md` | 虚构候选人「张三」的 Markdown 简历 | 演示简历解析 |
| `jobs_sample.json` | 6 条虚构岗位（覆盖数据/产品/运营/战略方向） | 演示岗位匹配 |

## 隐私红线（Contributor 必读）

1. 禁止提交任何真实简历、真实投递记录、联系方式、真实公司内部信息。
2. 新示例一律使用占位式命名：`张三 / XX大学 / 某互联网公司`。
3. 如误提交个人数据，请立即在 PR 中说明并删除（并考虑重写提交历史）。
4. 本项目的 `.gitignore` 已排除个人数据路径（`../秋招投递列表/`、`*.personal.*`、`private/`），请勿移除。
